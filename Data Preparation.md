# Fase 1: 
Prasyarat: 
1. Unduh Ollama di ollama.com.
2. Jalankan terminal, lalu tarik model yang ingin digunakan (contoh Llama 3): ollama run llama3
3. Pastikan Ollama tetap berjalan di background sebagai server API.

# Fase 2 & 3:
Prasyarat:
1. Buat sebuah folder bernama dataset_template di direktori yang sama dengan notebook-mu.
2. Masukkan 10 foto template KTP kosong (yang difoto miring/natural) ke dalam folder tersebut. Beri nama urut, misalnya template_1.jpg, template_2.jpg, dst. (Pastikan formatnya jpg/png).

# Fase 5:
Prasyarat:
Siapkan satu file font (misalnya arial.ttf, helvetica.ttf, atau ocr-a.ttf jika ingin mirip font komputer lama) dan letakkan satu folder dengan notebook-mu. Jika kamu memakai Windows, kamu bisa meng-copy file .ttf dari C:\Windows\Fonts. Di kode ini saya menggunakan nama file arial.ttf.
